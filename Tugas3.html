FAQ Interaktif

Apa itu jQuery? ▶
JQuery juga merupakan library JavaScript yang dapat mempercepat proses pembuatan website dengan sintaks yang tidak terlalu rumit, kodenya ringkas, dan fiturnya lengkap. jQuery membuat pemrosesan di HTML, seperti event handling, animasi, perubahan dan manipulasi dokumen, serta Ajax dapat menjadi lebih sederhana.
apa yang dimaksud dengan DOM manipulation? ▶
DOM MANIPULATION adalah teknik menggunakan JavaScript untuk mengubah struktur, konten, dan gaya halaman web secara dinamis setelah halaman dimuat, dengan cara memperlakukan elemen HTML sebagai objek yang bisa diakses dan dimodifikasi (menambah, menghapus, mengubah teks, atribut, atau gaya) tanpa perlu memuat ulang halaman, menciptakan pengalaman web yang interaktif dan responsif.
Apa fungsi .hide() dan .show()? ▶
Fungsi .hide() dan .show() adalah metode dalam JavaScript (sering digunakan dengan jQuery) untuk mengontrol visibilitas elemen HTML; .hide() menyembunyikan elemen (mirip display:none di CSS) sehingga tidak terlihat dan tidak memengaruhi tata letak, sedangkan .show() memunculkannya kembali ke tampilan awal, seringkali dengan efek transisi perlahan untuk menambah interaktivitas pada halaman web atau aplikasi.
Apa perbedaan antara .hover() dan CSS :hover? ▶
CSS :hover murni untuk tujuan gaya visual sederhana. .hover() jQuery adalah fungsi pintasan untuk mengikat dua penangan acara: satu untuk mouseenter (saat masuk) dan satu lagi untuk mouseleave (saat keluar), memungkinkan Anda menjalankan logika JavaScript yang lebih kompleks (seperti menambahkan/menghapus kelas dinamis, bukan hanya mengubah warna) saat kursor masuk atau keluar.
Apa fungsi .addClass() dalam jQuery? ▶
Fungsi $.addClass() di jQuery adalah untuk menambahkan satu atau lebih nama kelas CSS ke elemen HTML yang dipilih tanpa menghapus kelas yang sudah ada, memungkinkan manipulasi gaya (styling) atau perilaku elemen secara dinamis melalui JavaScript.
